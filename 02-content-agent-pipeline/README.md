# 02 · AI-агент для Telegram-канала

Цепочка из вакансии один в один: **собрать материал → сгенерировать контент → опубликовать → собрать статистику**.

```
RSS/Atom ──► SQLite (дедупликация) ──► Claude API: пост + промпт картинки
                                          │
                                          ▼
                         ComfyUI (SDXL) ──► картинка
                                          │
                                          ▼
                         Telegram Bot API ──► канал
                                          │
                                          ▼
                         Telethon ──► просмотры / репосты / реакции ──► SQLite
```

| Модуль | Шаг |
|---|---|
| `collect.py` | парсинг RSS 2.0 и Atom без сторонних библиотек, очистка HTML |
| `generate.py` | Claude Messages API, строгий JSON-ответ, валидация полей |
| `image.py` | ComfyUI HTTP API: подстановка промпта в workflow, новый seed, ожидание результата |
| `publish.py` | `sendPhoto` / `sendMessage`, учёт лимита подписи 1024 символа |
| `stats.py` | статистика через MTProto (Bot API её не отдаёт) |
| `storage.py` | SQLite: что собрано, что опубликовано, история метрик |
| `run.py` | оркестратор + CLI |

## Запуск

```bash
pip install -r requirements.txt
python -m pipeline.run --dry-run    # без ключей и сети: посты из data/sample_feed.xml → data/outbox/
cp .env.example .env                # заполнить ключи
python -m pipeline.run --limit 3    # боевой запуск (можно повесить на cron)
python -m pipeline.run --stats      # обновить статистику
python -m pytest tests              # тесты парсинга и валидации
```

## Принципы

- **Никаких тихих подмен.** Нет ключа — понятная ошибка и код выхода 2, а не «пост-заглушка».
  Режим `--dry-run` включается только явно, и всё, что он создаёт, помечено `[DRY-RUN]`.
- **Идемпотентность.** Материал публикуется один раз (ссылка — первичный ключ).
  Упавший материал помечается `failed` и не блокирует остальные.
- **Модель не выдумывает.** В системном промпте запрет на факты вне исходника; ответ строго JSON.
- Секреты только в `.env`, он в `.gitignore`.
