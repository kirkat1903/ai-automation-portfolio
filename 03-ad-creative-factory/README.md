# 03 · Фабрика рекламных креативов + анализ кампании

Закрывает блок вакансии «Привлечение рекламы»: производство креативов,
анализ эффективности и автоматическая корректировка стратегии.

## `banner_factory.py` — один CSV → креативы во всех форматах

| Формат | Размер |
|---|---|
| Квадрат ленты | 1080×1080 |
| Портрет ленты | 1080×1350 |
| Сторис / Reels | 1080×1920 (текст вне нижних ~18%, где интерфейс) |
| Широкий баннер | 1200×628 |

- изображения из папки (например, сгенерированные в Midjourney / ComfyUI) обрезаются по центру под формат;
- кегль подбирается автоматически, перенос по словам;
- если текст не влезает даже в минимальном кегле — креатив **не выпускается**, а скрипт говорит, что сократить;
- на каждый продукт — контакт-лист со всеми форматами для быстрого ревью.

```bash
pip install -r requirements.txt
python banner_factory.py data/products.csv -o output/
python banner_factory.py data/products.csv --images path/to/ai_images -o output/
```

## `campaign_analyzer.py` — какие креативы работают и куда переложить бюджет

- CTR, конверсия из клика, CPA, CPM по креативам;
- z-тест: значимо ли креатив хуже лидера, или данных пока мало;
- диагностика: «кликают, но не покупают» → проблема в оффере / посадочной;
  «покупают, но мало кликают» → переделывать визуал;
- бюджет на следующий период по Thompson sampling с минимальной долей на «разведку».

```bash
python campaign_analyzer.py --make-demo data/campaign_stats_DEMO_synthetic.csv
python campaign_analyzer.py data/campaign_stats_DEMO_synthetic.csv -o output/
```

> Данные в `data/campaign_stats_DEMO_synthetic.csv` — **синтетические**, сгенерированы
> с заданными «истинными» CTR/CR, чтобы проверить, что анализатор их находит.
> Пример отчёта: [`output/campaign_report.md`](output/campaign_report.md).
