# Чек-лист: мониторинг зрительной усталости

**Объект:** [diplom2-eye-asthenopia-monitoring](https://github.com/kirkat1903/diplom2-eye-asthenopia-monitoring)  
**Платформа:** Windows, Python 3.11, веб-камера.

## Smoke

- [ ] Запуск по инструкции из README.
- [ ] Главное окно отображается без визуальных дефектов.
- [ ] Камера показывает видеопоток.
- [ ] Лицо определяется в кадре.
- [ ] Счётчик морганий изменяется.
- [ ] Приложение закрывается штатно.

## Камера и устойчивость

- [ ] Запуск без камеры не приводит к аварийному завершению.
- [ ] Отказ в доступе к камере сопровождается понятным сообщением.
- [ ] Отключение камеры во время работы обрабатывается.
- [ ] После повторного подключения работа восстанавливается.
- [ ] Камера освобождается после закрытия приложения.
- [ ] Проверена работа при низком FPS и задержках потока.

## Распознавание лица и глаз

- [ ] Одно лицо по центру кадра.
- [ ] Лицо отсутствует или частично закрыто.
- [ ] Пользователь в очках.
- [ ] Плохое и контрастное освещение.
- [ ] Поворот и наклон головы.
- [ ] Быстрое и длительное закрытие глаз.
- [ ] Несколько лиц в кадре.
- [ ] При отсутствии лица моргания не начисляются.

## Расчёты и интерфейс

- [ ] Счётчик начинается с нуля.
- [ ] Одно моргание увеличивает счётчик на единицу.
- [ ] Частое моргание не вызывает двойного подсчёта.
- [ ] Проверены значения ниже, на и выше порога.
- [ ] Уведомления не дублируются бесконтрольно.
- [ ] Масштабирование Windows 100/125/150%.
- [ ] EXE запускается без установленного Python.
- [ ] В путях нет зависимости от профиля разработчика.
- [ ] Двухчасовой прогон не выявляет зависания и утечки памяти.
