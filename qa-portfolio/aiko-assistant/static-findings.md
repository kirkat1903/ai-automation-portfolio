# Статический анализ: Aiko

Находки требуют runtime-подтверждения.

## AIKO-SR-001 — внешние API

**Риск:** 401/403/429/5xx и timeout могут давать неодинаковый UX.  
**Проверка:** стабами вернуть каждый статус и проверить сообщение, retry и отсутствие повторного действия.

## AIKO-SR-002 — управление системой

**Риск:** ошибка распознавания может вызвать нежелательное действие.  
**Проверка:** похожие фразы, шум, неоднозначные названия и подтверждение опасных команд.

## AIKO-SR-003 — конфигурация и секреты

**Риск:** API-ключ может попасть в конфигурацию, лог или traceback.  
**Проверка:** поиск ключа во всех файлах и логах после успешного и ошибочного запроса.

## AIKO-SR-004 — восстановление микрофона

**Риск:** отключение устройства может остановить основной цикл.  
**Проверка:** hot unplug, смена устройства по умолчанию и занятый микрофон.

## AIKO-SR-005 — идемпотентность повторов

**Риск:** retry может дважды открыть программу, создать таймер или выполнить системное действие.  
**Проверка:** timeout после отправки и повтор с тем же intent/id.
