# Чек-лист: Aiko — голосовой помощник Windows

**Объект:** [voice-assistant](https://github.com/kirkat1903/voice-assistant)

## Установка и запуск

- [ ] Установка зависимостей по README.
- [ ] Первый запуск без API-ключа.
- [ ] Запуск с валидным и невалидным ключом.
- [ ] Секрет не записывается в репозиторий и логи.
- [ ] Автозапуск устанавливается предсказуемо.
- [ ] Повторный запуск не создаёт конфликтующие экземпляры.

## Голос и микрофон

- [ ] Русская и английская речь.
- [ ] Тишина, шум и музыка.
- [ ] Микрофон отсутствует, занят или отключён во время работы.
- [ ] Неточное распознавание команды.
- [ ] Уточнение неоднозначной команды.
- [ ] Режим «не слушай» приостанавливает распознавание.

## Команды Windows

- [ ] Запуск существующего и отсутствующего приложения.
- [ ] Открытие сайта и поискового запроса.
- [ ] Громкость и яркость на граничных значениях.
- [ ] Управление окнами и вкладками.
- [ ] Таймеры: ноль, отрицательное и большое значение.
- [ ] Потенциально опасная команда требует подтверждения.
- [ ] Ошибка внешней программы не завершает Aiko.

## Интеграции и интерфейс

- [ ] Нет сети, timeout, 401/403, 429 и 5xx.
- [ ] Повторный запрос не дублирует действие.
- [ ] Fallback TTS включается при отказе основного движка.
- [ ] Логи не содержат ключи и чувствительные данные.
- [ ] Некорректный или отсутствующий config.json обработан.
- [ ] Иконка в трее, меню и выход работают.
- [ ] Масштабирование 100/125/150%.
- [ ] Двухчасовой прогон стабилен.
