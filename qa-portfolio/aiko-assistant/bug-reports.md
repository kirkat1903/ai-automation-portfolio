# Баг-репорты: Aiko

## AIKO-BUG-001 — приложение не запускается при повреждённом config.json

**Статус:** воспроизведён 20.11.2026  
**Severity:** Major  
**Priority:** High  
**Окружение:** Windows, Python 3.11, ветка main.

### Предусловия

В `config.json` находится синтаксически некорректный JSON.

### Шаги

1. Сохранить резервную копию `config.json`.
2. Записать в файл `{ invalid json`.
3. Запустить `python voice_assistant.py`.

### Фактический результат

Приложение завершается с кодом 1 и необработанным `json.decoder.JSONDecodeError` из функции `load_config()`.

### Ожидаемый результат

Приложение сообщает о повреждённой конфигурации, использует безопасные значения по умолчанию либо предлагает восстановить файл. Traceback не должен быть единственной обратной связью.

### Рекомендация

Перехватывать `FileNotFoundError` и `json.JSONDecodeError`, валидировать обязательные поля и создавать резервную копию повреждённого файла.

## AIKO-BUG-002 — выключение и перезагрузка выполняются без второго подтверждения

**Статус:** подтверждён статическим анализом; опасное действие не запускалось  
**Severity:** Critical  
**Priority:** High.

### Основание

`handle_command()` после совпадения с `system_commands` сразу вызывает `run_system_command()`. Для `shutdown` используется `shutdown /s /t 0`, для `restart` — `shutdown /r /t 0`.

### Фактическое поведение по коду

Одного распознанного обращения «Айко, выключи компьютер» достаточно для немедленного действия.

### Ожидаемый результат

Ассистент задаёт отдельный вопрос подтверждения и выполняет команду только после явного ответа пользователя в течение ограниченного времени.

### Риск

Ложное распознавание, фоновая речь или похожая фраза могут привести к потере несохранённых данных.
